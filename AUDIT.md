# Аудит KUOG HALL — 7 ноября 2026

## Результат

Приложение собирается и проходит проверенные локальные сценарии на Windows, Node.js 24.14.1 и Microsoft Edge. Исправлены ошибки выдачи видео, проверки видеоканалов и подготовки AV1; восстановлена переносимость браузерных тестов. Добавлен повторяемый прогон `npm run test:audit`.

Работа выполнена в распакованной копии `hall5`. Исходный ZIP не изменялся. SHA-256 всех 26 извлечённых файлов данных и `.env` совпали с архивом; служебные файлы macOS не извлекались. Рабочая база, её backup, медиа и ключ сессий при проверках не использовались.

## Как устроено

- React + TypeScript + Vite: кабинет, редактор расстановки и клиентский плеер.
- Express: авторизация, загрузки, проекты, публикации, комментарии и выдача файлов.
- JSON-база: проверка структуры, атомарная запись, recovery-копия и блокировка второго процесса.
- FFmpeg/FFprobe: анализ исходника, MP4-превью, мобильные версии и проверенная AV1-копия для больших кадров.
- Three.js: помещение, GLB и видеотекстуры. Пять дорожек управляются общим контроллером; схема и одиночный экран используют тот же контент.
- Публикация сохраняет отдельный комплект готовых файлов: неудачная замена не должна повреждать доступный заказчику показ.
- Сеанс зрителя привязан к проекту, паролю и ревизии доступа. Одного подписанного URL для получения медиа недостаточно.

## Исправления

| Приоритет | Проблема | Изменение и подтверждение |

| Высокий | Ветка AV1/libaom не задавала положение цветовых отсчётов; FFprobe мог вообще не возвращать `chroma_location`. Корректная замена отклонялась. | Добавлен `chroma-sample-position=1`, а при отсутствии поля проверяется заголовок AV1 через FFmpeg. Сравнение всех декодированных кадров, таймкодов и аудио сохранено. Проходят создание и публикация 4800×2400, отказ для неподдерживаемой цветовой схемы и отклонение lossy-копии. |
| Средний | Проверка `SURFACE_MAP[key]` принимала унаследованные свойства `constructor`, `toString`, `__proto__` за канал. | Средний | Запускатель считал наличие двух каталогов доказательством корректной установки, в том числе после переноса между ОС. | Установка сверяется по платформе, архитектуре и SHA-256 lock-файла. Проверка заголовка читает stderr потоково с ограниченным буфером: длинный заголовок не теряется из-за усечения диагностического хвоста. Ошибка цветовой проверки теперь указывает конкретное поле.

## Ограничения и эксплуатация

Это локальная проверка перечисленных сценариев, а не подтверждение готовности любого интернет-развёртывания. Не выполнялись нагрузочные испытания, многочасовой просмотр, работа через слабую сеть, реальный iPhone/Safari/Android, Docker и запуск на macOS/Linux. Не измерялись производительность и синхронность пяти полноразмерных видео на оборудовании заказчика. Большой AV1 проверен короткой фикстурой; production smoke использует небольшие ролики. Остальные старые ручные браузерные скрипты, требующие готовый `/s/demo` и внешние фикстуры, в прогон не включены.

Данные из архива сохранены, но содержимое каждого реального проекта и его роликов отдельно не просмотрено. Юридическая корректность текстов не оценивалась: проверена только реализованная серверная логика.

Исходный архив содержит `.env`, базу и `data/secret.key`. Не используйте такой архив для публичного распространения. Исправленный дистрибутив `hall5-audited.zip` содержит код, сборку, тесты и отчёт, исключает `.env`, `data`, `node_modules` и кэши. Он рассчитан на новую установку; существующие проекты остаются в распакованной рабочей папке. Смена паролей и ключа на работающем сервере в этот аудит не входила.

Для запуска рабочей копии используйте `Запустить HALL5.cmd`. Для новой установки распакуйте чистый архив в отдельную папку и запустите тот же файл: будет создан новый `.env` с отдельным паролем. Первый запуск требует доступа к npm и загрузке FFmpeg.

Источники технической сверки: [FFmpeg: параметры libaom](https://ffmpeg.org/ffmpeg-codecs.html), [FFmpeg: AV1 bitstream filters](https://github.com/FFmpeg/FFmpeg/blob/master/doc/bitstream_filters.texi), [исходный ffprobe-static](https://github.com/derhuerst/ffprobe-static), [пакет FFprobe](https://www.npmjs.com/package/@ffprobe-installer/ffprobe).
